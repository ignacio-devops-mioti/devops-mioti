# devops-mioti

Repositorio del módulo **DevOps** de MIOTI Tech & Business School.

| Sesión | Carpeta | Qué hay |
|---|---|---|
| S2 | `linux/` | Ficheros para practicar comandos, permisos y editores |
| S3-S4 | `terraform/s3-bucket/` | Primer despliegue: un bucket S3 con etiquetas |
| S5 | `.github/workflows/` | Pipeline de CI/CD que ejecuta Terraform |
| S6 | `reto/` | Enunciado del reto final (RDS o EC2) |

> Importante: después de cada práctica, `terraform destroy`. Lo que no se destruye, se paga.
